# 要素数 3・4 の部分集合和

実装は `python/DP/subset_sum_fixed_k.py`。
相異なる正整数の集合 A と、要素数 K（3 または 4）、目標の和 M を渡す。
`count_subset_sum` は集合専用。`exists_subset_sum` と `find_subset_sum` は正整数の多重集合にも対応する。
入力の順序は任意で、入力は変更しない。

```python
from python.DP.subset_sum_fixed_k import count_subset_sum, exists_subset_sum, find_subset_sum

# convolution は mod 998244353 の畳み込み関数を用意する。
A = [1, 3, 4, 7, 9]
count = count_subset_sum(A, 3, 12, convolution)  # 1
exists = exists_subset_sum(A, 3, 12, convolution)
values = find_subset_sum(A, 3, 12, convolution)  # [1, 4, 7] など
values4 = find_subset_sum(A, 4, 15, convolution)  # [1, 3, 4, 7] など
# 同値の別要素を使用できる。
assert exists_subset_sum([2, 2, 2, 7], 3, 6, convolution)
assert find_subset_sum([2, 2, 2, 7], 3, 6, convolution) == [2, 2, 2]
# 解がなければ count は 0、exists は False、values は None。
```

復元結果は添字ではなく値のリスト。順序の保証はない。
`convolution(a, b)` は入力を変更せず、長さ `len(a)+len(b)-1` の
0 以上 998244353 未満の係数列を返すものとする。

## 正確な数え上げ

$f(x)=\sum_{a\in A}x^a$、$f_j(x)=f(x^j)$、$q=f^2$ とする。
$n=|A|<998244353$ なら $q$ の各係数は高々 n なので、
mod 998244353 の畳み込み1回で q の整数係数を正確に得られる。

K 要素部分集合の和を数える多項式を $E_K$ とすると、

$$6E_3=qf-3ff_2+2f_3,$$

$$24E_4=q^2-6qf_2+3f_2^2+8ff_3-6f_4.$$

求めるのは M 次の係数1つなので、残りは内積や A の走査で計算できる。
畳み込みは1回だけでよく、以降は Python の整数演算で処理する。
最終的な個数が法の倍数でも、存在判定を誤らない。

## 多重集合の判定・復元

各値の出現数を高々 K 個に制限してから、f の係数をその出現数とする。
K 個の選択にはこれで十分で、入力の各要素は高々1回だけ使用する。
Newton の恒等式は同値の要素を区別した選択数にも成立する。
判定では制限後の選択数が正かどうかを調べる。これは元の多重集合の数え上げではない。
q の係数上界は n max(f) となるため、法以上になりうる場合は以下の桁分割を使う。

$P=E_2$ の s 次係数は `(q[s] - (f[s//2] if s % 2 == 0 else 0)) // 2`。
3 要素の場合、a を固定したときの残り2要素の候補数は、
$P[M-a]$ から特定の1要素 a を含むペアの個数 $f[M-2a]-[M=3a]$を引けばよい。
候補数が正になる a を見つけた後だけ、b を走査して c=M-a-b を探す。
二重ループだが、内側の走査は高々1回で、畳み込み後の時間は O(N)。

4 要素の場合、まず

$$3E_3=Pf-f_2f+f_3$$

で三つ組の個数を計算する。$Pf$ の係数は法を超えうるため、
P の係数を基数 $B=\lfloor(998244353-1)/n\rfloor+1$ の各桁に分ける。
各桁と f の畳み込み係数は $n(B-1)<998244353$ なので、
桁ごとの畳み込み結果を整数として足し合わせれば正確な $Pf$ が得られる。
$f_2f$ も係数上界 n max(f) が法未満なら分割不要で、それ以外は同じ桁分割を使う。

特定の1要素 a を含まない、和 M-a の三つ組の個数は

$$E_3[M-a]-P[M-2a]+f[M-3a]-[M=4a].$$

これが正になる a を選び、a を1個だけ除く。その1要素を含むペアを P から除いて3要素の復元に帰着する。
復元時は値の不一致ではなく、残りの出現数で使用可能性を判定する。
範囲外の係数は 0 とする。

## 計算量と制限

N=max(A)。通常の長さ上限 $2^{23}$ の NTT では、
数え上げと3要素復元に $2N+1\le 2^{23}$、
4要素復元に $3N+1\le 2^{23}$ が必要。
4要素復元での P の係数分割はこの範囲内で高々3桁。
集合では数え上げは畳み込み1回、3要素復元も1回、4要素復元は高々5回となる。
多重集合では頻度に応じて桁分割が追加される。
多重集合の入力長を L とすると、時間 O(L+N log(N+1))、空間 O(L+N)。
制限後の要素数 n は法未満とする。Python の整数演算を単位として評価している。
独自の長さ制限を持つ畳み込みを使う場合は、その制限にも従う。
空集合など要素数が足りない場合は、畳み込みなしで終了する。
