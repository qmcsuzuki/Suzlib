区間内積の重みの意味は `sum(W[i]*A[i]*B[i])` として明記した。
W を省略した既存の通常使用では意味は変わらない。W を指定して初期値を与える場合は
結果が変わるため、この修正も main に直接入れず PR のレビュー対象とする。
いずれも漸近的な計算量は維持する。

## 検証と限界

- 既存の STANDALONE 32 本は整備前と main の整備後の両方で成功。
- 修正前の main に対し、上表の各不具合の再現例が失敗することを確認。
- 修正後は既存テストの拡充と新規 2 本を含む STANDALONE 34 本が成功。
- 重み付き内積を全区間の直接計算と比較。A/B/W の個別省略、零重み、負値、空列も確認。
- Floyd–Warshall の混合した辺追加を毎回の全距離再計算と比較。
- Garner を最小公倍数の一周期の全列挙と比較。負の剰余・非互いに素の法・最小正解も確認。
- 最小費用流の sparse/dense と負費用 DAG を、各辺の流量の全列挙と比較。
- SCC を全頂点対到達可能性、マッチングの辺・頂点分類を最大マッチングの全列挙と比較。
- 有向・無向トレイル分解の連続性・全辺被覆・次数による最小本数を確認。
- 部分和の実装を長さ 0〜7、値 0〜3、全容量について部分和の全列挙と比較し、復元も確認。
- 全 Python ファイルの構文解析、内部 import 先の存在、diff の空白チェックを実施。

この実行環境では PyPy3 がなく、ローカル実行は CPython 3.12 による。
外部ジャッジの PROBLEM 検証はこの点検では再実行していない。
静的点検と有限の比較検証であり、全入力に対する正しさの証明を代替するものではない。
